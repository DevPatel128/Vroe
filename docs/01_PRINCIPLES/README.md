# 01 Principles

**Status:** Review · **Last updated:** 2026-09-19 · **Owner:** Vroe Labs · **Version:** 1.0

- **Purpose:** the durable rules everything else follows.
- **Belongs here:** principles that change rarely and that a reviewer could hold
  a change against.
- **Does not belong here:** plans, specifications, implementation detail, metrics,
  research findings.
- **Important files:** [PRINCIPLES.md](PRINCIPLES.md).
- **Source of truth:** PRINCIPLES.md is the only statement of the rules. The root
  `CLAUDE.md` summarises them as an agent entry point and links back.
