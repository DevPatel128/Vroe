# Experience, in the design layer

**Status:** Review · **Last updated:** 2026-09-19 · **Owner:** Vroe Labs · **Version:** 1.0

This file deliberately does not describe the product experience. That is owned by
[02_PRODUCT/EXPERIENCE.md](../02_PRODUCT/EXPERIENCE.md), and a second description
would drift from it. It records only where the design layer realises that
experience, so a designer can find each piece:

| The experience needs | The design layer provides | Where |
| --- | --- | --- |
| Status read first on a product page | The "Where this stands" callout with a coral rule, and the status pills | [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md), "Component conventions" |
| A warm, editorial voice | Display serif headlines split into lines, and the coral full stop | [BRAND-GUIDE.md](BRAND-GUIDE.md), [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md) |
| Plain, honest words | Voice and link-text rules | [CONTENT.md](CONTENT.md) |
| Usable by everyone | Focus, skip link, contrast, motion | [ACCESSIBILITY.md](ACCESSIBILITY.md) |
| A layout that holds at every width | Breakpoints and gutters | [RESPONSIVE.md](RESPONSIVE.md) |
