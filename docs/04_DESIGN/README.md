# 04 Design

**Status:** Review · **Last updated:** 2026-09-19 · **Owner:** Vroe Labs · **Version:** 1.0

- **Purpose:** how the site looks, reads and behaves for everyone.
- **Belongs here:** the brand contract, the reusable visual rules, accessibility,
  responsive behaviour, and the content rules and voice.
- **Does not belong here:** the product experience itself, which is described once
  in [02_PRODUCT/EXPERIENCE.md](../02_PRODUCT/EXPERIENCE.md); build and deploy
  detail ([05_ENGINEERING](../05_ENGINEERING/README.md)).
- **Important files:** [BRAND-GUIDE.md](BRAND-GUIDE.md) (read-only; the client's
  document), [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md), [ACCESSIBILITY.md](ACCESSIBILITY.md),
  [RESPONSIVE.md](RESPONSIVE.md), [CONTENT.md](CONTENT.md),
  [EXPERIENCE.md](EXPERIENCE.md) (a pointer, not a second description).
- **Source of truth:** the brand guide is the contract and the design system
  records how it is expressed in CSS. Do not introduce a colour, radius or width
  the brand guide does not define; add it there first.
