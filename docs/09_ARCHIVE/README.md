# 09 Archive

**Status:** Review · **Last updated:** 2026-09-19 · **Owner:** Vroe Labs · **Version:** 1.0

- **Purpose:** keep important historical reasoning without letting it compete with
  current documentation.
- **Belongs here:** rejected ideas, superseded documents, old research, old
  decisions.
- **Does not belong here:** anything current. A document here must be marked
  Archived or Superseded, and `npm run test:docs` checks it.
- **Important folders:** [REJECTED-IDEAS](REJECTED-IDEAS/README.md),
  [SUPERSEDED-DOCUMENTS](SUPERSEDED-DOCUMENTS/README.md),
  [OLD-RESEARCH](OLD-RESEARCH/README.md), [OLD-DECISIONS](OLD-DECISIONS/README.md).
- **Source of truth:** nothing here is current truth. Archive rather than delete;
  never treat an archived document as guidance.
